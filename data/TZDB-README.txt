Europe/Madrid — IANA time zone database, release 2026c

The file europe-madrid-tzdb-2026c.tzif is the compiled TZif zone file for
Europe/Madrid from the IANA Time Zone Database. The tz database is in the
public domain. Source and documentation: https://www.iana.org/time-zones

The cancellation service prefers the host's installed zone database; this
copy is a fallback for systems such as Windows that lack one. Time-zone law
and database rules can change. Update the host tzdata or replace this fallback
with a newer official Europe/Madrid TZif file when appropriate.
